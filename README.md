# Kondiciogram

Jednostránkový web: 7 otázek, náhled biorytmů na 30 dní a QR platba měsíčního předplatného (SPAYD, trvalý příkaz `FRQ:1M`).

- Nastavení (účet, cena, endpoint backendu) je v objektu `CONFIG` na začátku skriptu v `index.html`.
- Odesílání e-mailů a ověření plateb zatím není napojeno (`CONFIG.endpoint` je prázdný).
- Obsah je určen pro zábavu.
